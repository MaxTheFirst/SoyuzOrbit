# Logic-PC: схема + встроенный экран

Единый Python-проект с одним окном:
- слева визуальная электрическая схема (питание, блоки процессора, шины),
- по проводам бегут «электроны»,
- справа на схеме встроен экран-калькулятор (без второго окна).

Система запускается только при достаточном токе питания.

## Что реализовано

1. Электрическая часть:
- кнопка `Power ON/OFF`,
- контроль тока (`A`) и проверка порога для загрузки,
- тактовая линия и активные шины,
- анимация электронов по проводам,
- RAM (оперативная память) и HDD (долговременное хранилище) в схеме.

2. Простейший CPU на логических блоках:
- логические элементы (`NAND`, `NOT`, `AND`, `OR`, `XOR`),
- 1-битный полный сумматор и 8-битная ALU,
- регистры `PC`, `ACC`, `IR`,
- фазы `FETCH -> DECODE -> EXECUTE -> WRITEBACK`.
- вычисление логических элементов идет через транзисторный `SPICE-like` слой
  (CMOS pull-up/pull-down + RC-осаждение узлов), чтобы приблизить поведение к железу
  и сохранить производительность в real-time.

3. Калькулятор на подключенном экране:
- при запуске: приветствие и prompt `calc>`,
- поддерживается только формат `A+B`,
- `A` и `B` ограничены диапазоном `0..999`,
- вычисление суммы выполняется через транзисторный ALU-путь.

## Физическая модель (что именно симулируется)

- Питание: проверка порога по напряжению и току (`boot_ready`).
- Такт: аналоговый RC-генератор c пороговым переключением (Schmitt-подобная модель).
- Логика: CPU-гейты (`NAND/NOT/NOR` и производные) считаются через транзисторный `SPICE-like` CMOS слой.
- Шины/линии: линии представлены напряжениями с RC-динамикой; логические состояния получаются порогованием.
- Шины/линии в GUI теперь считаются через MNA-решатель (`SpiceMNA`) и читаются как реальные узловые напряжения.
- RAM/HDD:
- RAM представлена аналоговыми бит-ячейками (напряжения с утечкой) с чтением/записью через пороги.
- HDD представлена наборами секторов и периодической синхронизацией из RAM.
- Важно: это облегченный SPICE-like подход (reduced-order), чтобы модель оставалась исполнимой в реальном времени.

## Запуск

```bash
python3 main.py
```

Если получаешь ошибку про `Tkinter`/`_tkinter`, значит текущая сборка Python без GUI-модуля Tk.
Нужен Python с поддержкой Tk (например, официальный installer Python для macOS).

## Управление

1. Нажми `Power ON`.
2. Ползунком тока выстави значение не ниже порога (на экране отображается нужное значение).
3. После этого калькулятор на встроенном экране станет активным.
4. Вводи выражения `A+B` (например `105+37`) и получай результат.
5. Внизу слева появится второй экран RAM/HDD с live-дампом памяти и синхронизацией на HDD.
6. Кликни по любому блоку схемы, чтобы открыть окно его внутреннего устройства и линий тока.

## RAM Hex Dump

- `RAM hex dump` показывает байты памяти в шестнадцатеричном виде.
- Строка вида `20: 7F 00 01 ...` означает:
- `20` это стартовый адрес строки (`0x20`),
- дальше идут значения байтов по адресам `0x20, 0x21, ...`.
- Почему 256 байт:
- RAM хранится как `bytearray(256)`, поэтому адреса `0x00..0xFF`.
- Какие ячейки заняты:
- занятыми считаются ячейки с ненулевым значением (`!= 0`),
- в мониторе показываются `RAM used cells (non-zero)` и `Used addr preview`.

## Структура

- `main.py` — точка входа
- `ui/attached_screen_app.py` — единый GUI со схемой и экраном
- `simulation/logic_cpu.py` — логические элементы + CPU
- `simulation/electrical.py` — питание, ток, такт, состояния проводов
- `simulation/transistor_spice.py` — упрощенный SPICE-like CMOS-движок
- `simulation/calculator_system.py` — экранный калькулятор `A+B`
- `simulation/full_spice_mna.py` — полный MNA-решатель (R/I/V/C/MOS Level-1 + Newton)
