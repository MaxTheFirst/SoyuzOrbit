# Модели волновой оптики

В репозитории есть несколько самостоятельных скриптов для исследования скалярной волновой оптики.

## Линзы

Добавлены модели для схемы `источник -> линза -> экран`:

- `lens_focus_basic.py` — как реальная сферическая линза фокусирует коллимированный пучок, с картой интенсивности вдоль оси.
- `lens_focus_vs_theory.py` — сравнение расчётного положения изображения с фактическим фокусом для конечного расстояния до источника.
- `lens_parameter_sweep.py` — влияние апертуры линзы на размер пятна, дифракционный предел и сдвиг фокуса.
- `lens_real_vs_ideal.py` — отличие реальной сферической линзы от идеальной параболической фазовой маски.
- `lens_wave_optics.py` — общий модуль с физикой линзы и волновой пропагацией.

## Что именно учитывается

Новые модели физичнее простого `thin lens`-приближения:

- точная сферическая толщина линзы;
- конечная круглая апертура;
- показатель преломления BK7 по формуле Sellmeier;
- фазовая задержка `k (n - 1) t(x, y)`;
- потери на двух поверхностях при нормальном падении;
- распространение поля методом углового спектра.

Это по-прежнему скалярная монохроматическая модель. Она хорошо подходит для учебного исследования дифракции, фокусировки, смещения фокуса и сферической аберрации, но не включает поляризацию, рассеяние на шероховатости, многолучевые переотражения внутри линзы и дисперсионную хроматику в широком спектре.
