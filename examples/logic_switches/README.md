# Простые логические схемы на переключателях

В этой папке лежат максимально простые демонстрации логики на базовых элементах проекта.

Используются только простые компоненты:

- `Battery`
- `Switch`
- `SPDT Switch`
- `Resistor`
- `LED`
- `Bulb`
- `Ground`

## Что здесь есть

### `and_series_switches.json`

Логическая операция `И`.

Идея:

- два обычных переключателя стоят последовательно;
- ток доходит до LED только если оба замкнуты.

Соответствие:

- `SW_A.closed = 0`, `SW_B.closed = 0` -> выход `0`
- `SW_A.closed = 1`, `SW_B.closed = 0` -> выход `0`
- `SW_A.closed = 0`, `SW_B.closed = 1` -> выход `0`
- `SW_A.closed = 1`, `SW_B.closed = 1` -> выход `1`

### `or_parallel_switches.json`

Логическая операция `ИЛИ`.

Идея:

- два обычных переключателя стоят параллельно;
- если замкнут хотя бы один путь, LED получает питание.

Соответствие:

- `0, 0` -> `0`
- `1, 0` -> `1`
- `0, 1` -> `1`
- `1, 1` -> `1`

### `xor_crossed_spdt_switches.json`

Логическая операция `XOR`.

Идея:

- используются два перекидных `SPDT Switch`;
- “путники” между ними перекрещены;
- поэтому LED загорается только когда переключатели стоят в разных положениях.

Соответствие:

- `A, A` -> `0`
- `A, B` -> `1`
- `B, A` -> `1`
- `B, B` -> `0`

### `toggle_lamp_switch.json`

Одна кнопка/переключатель для лампы.

Идея:

- это самый простой вариант схемы “нажал -> горит, нажал еще раз -> не горит”;
- используется обычный `Switch` в роли фиксируемой кнопки.
- в демо-параметрах лампы занижена `filament_operating_temp_c`, чтобы накал был виден быстрее в короткой симуляции.

Важно:

- в текущем проекте это не “моментальная” кнопка с пересчетом на лету;
- переключатель меняется на холсте, затем запускается симуляция.

## Как пользоваться в GUI

1. Открой нужный JSON.
2. Для `Switch` сделай двойной клик по переключателю:
   - разомкнут -> замкнут
   - замкнут -> разомкнут
3. Для `SPDT Switch` двойной клик меняет положение:
   - `A` <-> `B`
4. Нажми `Старт`.
5. Смотри:
   - `LED.brightness`
   - `Bulb.glow`
   - токи и напряжения на графиках

## Как запускать из CLI

```bash
python3 run_sim.py examples/logic_switches/and_series_switches.json
python3 run_sim.py examples/logic_switches/or_parallel_switches.json
python3 run_sim.py examples/logic_switches/xor_crossed_spdt_switches.json
python3 run_sim.py examples/logic_switches/toggle_lamp_switch.json
```

## Что можно проверять

- разницу между последовательным и параллельным включением ключей;
- простейшую физическую реализацию `AND`, `OR`, `XOR`;
- как схема XOR получается без микросхем, только на переключателях;
- как одна фиксируемая кнопка управляет лампой.
