# Усилитель С Термозависимой Обратной Связью: Подробный Разбор Физики, Графиков И Разницы Между Thermal И Frozen

## 1. Цель Кейса

Этот кейс нужен не для того, чтобы показать просто "нагрев есть", а для более строгой инженерной задачи:

- есть усилительный каскад;
- в цепи отрицательной обратной связи стоит термозависимый элемент;
- электрическое поведение схемы зависит от температуры;
- температура меняется во времени из-за рассеиваемой мощности;
- из-за этого уже меняется не только число "сопротивление стало больше", а именно форма и амплитуда выходного сигнала.

То есть это именно пример того, зачем вообще в такой системе нужен совместный электротепловой расчет.

## 2. Какие Файлы Относятся К Этому Кейсу

- `examples/thermal_feedback_amp.json` - основной thermal-вариант
- `examples/thermal_feedback_amp_frozen.json` - контрольный frozen-вариант
- `examples/thermal_feedback_amp_compare.py` - скрипт сравнения, метрик и отдельных PNG

## 3. Что Именно Сравнивается

Схема в обоих JSON почти одинаковая:

- `SRC` - входной `AC Generator`
- `OA1` - `OpAmp`
- `BULB_FB` - лампа в цепи обратной связи
- `R_G` - нижнее плечо обратной связи
- `R_LOAD` - нагрузка выхода
- `VM_IN` - измерение входного узла
- `VM_OUT` - измерение выходного узла
- `OUT_MON` - захват выходной волны

Разница только в одном:

- в `thermal_feedback_amp.json` температура лампы считается честно;
- в `thermal_feedback_amp_frozen.json` у `BULB_FB` включен параметр `"freeze_temperature": true`.

Значит, электрическая топология одинакова, а отличается только тепловая динамика. Это и есть правильная контрольная постановка для A/B-сравнения.

## 4. Топология И Почему Она Вообще Дает Нужный Эффект

Это неинвертирующий усилитель.

Приближенно, пока `OpAmp` не уперся в ограничения и петля обратной связи работает в линейной области, замкнутый коэффициент усиления задается стандартной оценкой:

```text
K_cl ~ 1 + R_fb / R_g
```

Здесь:

- `R_fb` - это `BULB_FB`
- `R_g` - это `R_G`

Следовательно:

- если лампа холодная, `R_fb` меньше;
- если лампа нагрелась, `R_fb` больше;
- значит, замкнутый коэффициент усиления растет во времени.

Именно поэтому late-участки в thermal-варианте выходят сильнее, чем early-участки, а frozen-контроль остается почти стационарным.

## 5. Как В Проекте Вообще Считается Электрическая Схема

Система решает схему по узловым напряжениям во времени.

На каждом шаге времени применяется первый базовый закон:

```text
Для каждого узла: sum I_k = 0
```

То есть в каждом узле выполняется закон Кирхгофа по токам.

Каждый компонент возвращает:

- вектор токов через свои выводы;
- локальную матрицу производных по напряжениям, то есть локальный Jacobian.

После этого из всех компонентов собирается общая нелинейная система:

```text
F(V) = 0
```

И далее она решается итерационно методом Ньютона:

```text
J(V_n) * dV = -F(V_n)
V_(n+1) = V_n + dV
```

Где:

- `V` - вектор узловых напряжений;
- `F(V)` - невязка по законам Кирхгофа;
- `J(V)` - матрица Якоби;
- `dV` - поправка напряжений на итерации.

Это важно, потому что схема содержит нелинейные элементы и тепловую память. Обычным "подставили формулу усиления и все" такой кейс уже не описать.

## 6. Как Считается Лампа В Обратной Связи

### 6.1. Электрическая Часть

Лампа здесь моделируется как двухполюсник с сопротивлением, зависящим от температуры.

Сначала из паспортных значений вычисляется горячее сопротивление:

```text
R_hot = V_rated^2 / P_rated
```

Далее из коэффициента `cold_ratio` вычисляется холодное сопротивление:

```text
R_cold = R_hot / cold_ratio
```

В коде для этой лампы:

- `rated_voltage_v = 6.0`
- `rated_power_w = 0.45`
- `cold_ratio = 4.0`

Значит:

```text
R_hot = 6^2 / 0.45 = 80 Ohm
R_cold = 80 / 4 = 20 Ohm
```

Именно поэтому в начале симуляции сопротивление лампы около `20 Ohm`.

Далее сопротивление растет с температурой по линейному закону относительно опорной температуры:

```text
R(T) = R_cold * (1 + alpha * (T - T_ref))
```

Где коэффициент `alpha` выбирается так, чтобы при `filament_operating_temp_c` получилось нужное отношение между холодным и горячим сопротивлением:

```text
alpha = (R_hot / R_cold - 1) / (T_hot - T_ref)
```

После этого ток через лампу считается как через обычный резистивный элемент:

```text
I = V / R(T)
G = 1 / R(T)
```

То есть сама нелинейность здесь идет не по току как у диода, а через медленно меняющуюся температуру.

### 6.2. Тепловая Часть

Лампа получает мгновенную электрическую мощность:

```text
P = I^2 * R = V * I
```

Эта мощность идет в тепловую модель.

В проекте используется двухузловая тепловая схема:

- внутренний "junction / filament" узел;
- поверхностный "case / surface" узел.

Уравнения по сути такие:

```text
C_j * dT_j/dt = P - (T_j - T_s) / R_js
C_s * dT_s/dt = (T_j - T_s) / R_js - (T_s - T_amb) / R_sa
```

Где:

- `T_j` - внутренняя температура лампы;
- `T_s` - температура поверхности;
- `T_amb` - температура окружающей среды;
- `C_j` - внутренняя теплоемкость;
- `C_s` - теплоемкость поверхности;
- `R_js` - тепловое сопротивление между внутренним узлом и поверхностью;
- `R_sa` - тепловое сопротивление от поверхности к воздуху.

В дискретном виде на шаге `dt` это интегрируется прямо во времени.

### 6.3. Что Делает Frozen-Режим

Если включен параметр:

```json
"freeze_temperature": true
```

то тепловая интеграция для компонента не выполняется.

Тогда принудительно держится:

```text
T_j = T_ref
T_s = T_ref
```

Из этого сразу следует:

```text
R(T) = const
```

То есть frozen-вариант нужен именно как физически осмысленный контрольный образец:

- электрический закон тот же;
- топология та же;
- меняется только отсутствие тепловой эволюции.

## 7. Как Считается Операционный Усилитель

Это не идеальный `OpAmp`, а физически ограниченная модель.

### 7.1. Дифференциальное Усиление

Сначала формируется ошибка между входами:

```text
e = V+ - V- + V_offset - V_cm / CMRR - V_supply_mid / PSRR
```

Где:

- `V+` и `V-` - напряжения на входах;
- `V_offset` - входовое смещение;
- `CMRR` - подавление синфазной составляющей;
- `PSRR` - подавление влияния питания.

Желаемое внутреннее выходное напряжение затем ограничивается через `tanh`, чтобы модель не вылетала бесконечно далеко:

```text
V_desired = V_mid + V_span * tanh(A_ol * e / V_span)
```

Это означает:

- при малой ошибке поведение почти линейное;
- при большой ошибке модель плавно уходит к шинам питания.

### 7.2. Доминирующий Полюс

Далее вводится однополюсная динамика:

```text
tau = 1 / (2 * pi * f_p)
alpha = dt / (tau + dt)
V_pole = V_prev + alpha * (V_desired - V_prev)
```

То есть усилитель не может мгновенно попасть в желаемое состояние. У него есть внутренняя полоса.

### 7.3. Slew Rate

Потом ограничивается максимальная скорость изменения:

```text
|dV/dt| <= SR
```

В дискретной форме:

```text
|Delta V| <= SR * dt
```

Это важно именно для формы сигнала. Даже если тепловой gain вырос, усилитель не может бесконечно быстро перестроить выход.

### 7.4. Ограничение Выходного Тока

Выходной каскад тоже не идеален.

Вместо бесконечно сильного идеального источника используется закон:

```text
I_out = I_lim * tanh(((V_out - V_target) / R_out) / I_lim)
```

То есть:

- пока требуемый ток умеренный, поведение почти линейное;
- при больших токах выход мягко ограничивается.

Следовательно, даже если формула `1 + R_fb / R_g` обещает рост gain, на практике реальный сигнал все равно ограничивается динамикой `OpAmp`.

## 8. Почему От Прогрева Меняется Не Только Амплитуда, Но И Форма

Если бы вся система была идеально линейной и без ограничений, то рост `R_fb` дал бы просто масштабирование выхода.

Но здесь одновременно есть:

- температурно меняющееся `R_fb`;
- конечная полоса усилителя;
- ограничение slew rate;
- ограничение выходного тока;
- многогармонический входной сигнал.

Значит, происходит следующее:

1. Лампа греется и увеличивает `R_fb`.
2. Замкнутый коэффициент усиления растет.
3. Выход начинает сильнее раскачиваться.
4. При больших амплитудах усиливается влияние неидеальности `OpAmp`.
5. Поэтому late-форма уже не совпадает с простым "early * constant".

То есть различие между thermal и frozen здесь физически содержательное: это не косметический drift параметра, а изменение режима работы всей замкнутой системы.

## 9. Что Дополнительно Делает Пространственная Тепловая Связь

В движке есть и еще один уровень тепловой физики: близко расположенные компоненты могут обмениваться теплом через surface-to-surface coupling.

По сути, для пары компонентов учитывается поток:

```text
Q_dot ~ (T_surface,2 - T_surface,1) / R_link
```

При этом `R_link` зависит от:

- расстояния на схеме;
- `contact_thermal_resistance_k_per_w`;
- коэффициента `thermal_coupling_gain`.

Для данного кейса главный эффект все равно дает собственный нагрев лампы, но сама архитектура системы допускает и межкомпонентное тепловое влияние.

Итак:

- frozen-пики стоят почти на месте;

### 10.5. Почему Ток `OA1` При Этом Не Растет

На первый взгляд может показаться, что если выходная амплитуда выросла, то и ток `OA1` должен обязательно вырасти.

Но расчет показывает обратное:

- peak `OA1.output_current_a` thermal: `0.1455 A`
- peak `OA1.output_current_a` frozen: `0.1495 A`

Это физически нормально.

Причина в том, что ток выхода `OpAmp` идет не только в нагрузку `R_LOAD`, но и в ветвь обратной связи.

При прогреве лампы:

- выходное напряжение действительно растет;
- ток в `R_LOAD` немного растет;
- но ток через `BULB_FB` падает сильнее, потому что `R_fb` вырос очень существенно.

Итог:

- суммарный выходной ток `OpAmp` может даже уменьшиться;
- одновременно амплитуда выходного напряжения при этом все равно растет.

Это как раз хороший пример, почему нужно смотреть не один параметр, а сразу несколько взаимосвязанных графиков.

## 14. Что На Этих Графиках Имеет Смысл Анализировать

### 14.1. Связь Между Температурой И Сопротивлением

Если система физически работает правильно, то:

- график температуры лампы должен расти;
- график `R_fb` должен расти синхронно;
- frozen-контроль должен оставаться почти горизонтальным.

Если этого нет, значит thermal part в данном кейсе не влияет на электрический закон.

### 14.2. Связь Между `R_fb` И Gain

Дальше нужно смотреть:

- растет ли `R_fb`;
- растет ли одновременно rolling gain.

Если `R_fb` растет, а gain нет, значит усилитель уже полностью уперся в ограничения и эффект прогрева электрически не проходит дальше.

В текущем кейсе эффект проходит.

### 14.3. Связь Между Gain И Формой Волны

После этого нужно сравнить:

- `wave-early`
- `wave-late`
- `late-difference`

Если late-окно отличается от early-окна сильнее, чем в frozen-контроле, значит прогрев реально меняет форму сигнала по мере хода расчета.

### 14.4. Связь Между Формой Волны И Током `OA1`

Наконец, график `opamp-current` нужен для проверки, не объясняется ли весь эффект банальным токовым упором.

В нашем случае картина тоньше:

- выходное напряжение thermal растет;
- но суммарный ток `OA1` слегка снижается;
- следовательно, причина не в том, что усилитель "просто сильнее качает ток", а в перераспределении токов внутри петли ООС из-за роста `R_fb`.

## 15. Главный Физический Вывод

Этот кейс показывает уже не игрушечный "нагрев есть / нагрева нет", а вполне инженерную цепочку причинности:

```text
рассеиваемая мощность
-> рост температуры лампы
-> рост сопротивления лампы в обратной связи
-> рост замкнутого коэффициента усиления
-> изменение поздней формы выходного сигнала относительно ранней
-> отличие от frozen-контроля
```

Именно это и является содержательным преимуществом электротепловой симуляции: система считает не только мгновенную электрическую схему, но и медленную эволюцию параметров, которая потом меняет уже сам аудио- или сигнальный результат.
