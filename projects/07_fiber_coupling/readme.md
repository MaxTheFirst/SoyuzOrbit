# Проект 07. Ввод света в оптоволокно

## Коротко

Оптоволокно - это тонкий световой провод. Оно не просто "трубка для света". Внутри него свет распространяется как волна, которая должна подходить к разрешенным формам поля внутри волокна.

В этом проекте мы смотрим, насколько хорошо сфокусированное световое пятно попадает в одномодовое оптоволокно.

Главная идея:

```text
хороший ввод = пятно похоже на моду волокна по размеру и положению
```

## Что такое оптоволокно

У оптоволокна есть две основные части:

```text
сердцевина -> область, где в основном идет свет
оболочка   -> материал вокруг сердцевины
```

Показатель преломления сердцевины немного больше, чем у оболочки:

```text
n_core > n_clad
```

Из-за этого свет удерживается около сердцевины.

## Что такое мода

Мода - это разрешенная форма волны внутри волокна.

Для простого понимания:

```text
мода = форма светового пятна, которое волокно умеет хорошо вести
```

В одномодовом волокне в основном есть одна главная мода. Она похожа на гладкое гауссово пятно.

## Что такое одномодовое волокно

Волокно называется одномодовым, если в нем распространяется только одна основная мода.

Простой критерий:

```text
V < 2.405
```

Где:

```text
V = 2 * pi * a * NA / lambda
```

Тут:

- `a` - радиус сердцевины;
- `NA` - числовая апертура волокна;
- `lambda` - длина волны.

Числовая апертура:

```text
NA = sqrt(n_core^2 - n_clad^2)
```

## Что мы здесь исследуем

Скрипт отвечает на вопросы:

1. Является ли выбранное волокно одномодовым?
2. Как выглядит основная мода волокна?
3. Что будет, если сфокусированное пятно:
   - идеально совпадает с модой;
   - слишком маленькое;
   - слишком большое;
   - смещено в сторону.

## Что такое overlap efficiency

Чтобы понять, сколько света вошло в волокно, нужно сравнить две формы поля:

```text
поле сфокусированного пятна
поле моды волокна
```

Если они совпадают, ввод почти 100 процентов.

Если пятно больше, меньше или смещено, часть света не попадает в основную моду.

Математически это считается через перекрытие:

```text
eta = |integral(E_focus * conj(E_mode) dA)|^2 /
      (integral(|E_focus|^2 dA) * integral(|E_mode|^2 dA))
```

Для человека без физики:

```text
eta показывает, насколько две световые формы похожи друг на друга
```

## Как работает скрипт

1. Задаются параметры волокна:

- длина волны;
- радиус сердцевины;
- показатель преломления сердцевины;
- показатель преломления оболочки.

2. Считается `NA`.

3. Считается `V-number`.

4. Проверяется условие одномодовости.

5. Оценивается радиус основной моды.

6. Строятся поля:

- мода волокна;
- хорошо сфокусированное пятно;
- слишком маленькое пятно;
- слишком большое пятно.

7. Считается эффективность ввода при смещении пятна.

8. Считается эффективность ввода при неправильном размере пятна.

## Что должно появиться

В консоли:

- длина волны;
- радиус сердцевины;
- показатели преломления;
- `NA`;
- `V-number`;
- вывод, одномодовое волокно или нет;
- оценка радиуса моды;
- проценты ввода для разных пятен.

На графиках:

- мода волокна;
- несколько сфокусированных пятен;
- потери от бокового смещения;
- потери от неправильного размера пятна.

## Как читать результат

Если график ввода быстро падает при смещении, значит волокно требует точного совмещения.

Если пятно слишком маленькое или слишком большое, эффективность ввода падает даже без смещения.

Лучший случай - когда сфокусированное пятно похоже на моду волокна.

## Почему это связано с темой линз и волн

Линза нужна, чтобы сфокусировать свет в торец волокна.

Но просто попасть светом в сердцевину недостаточно. Нужно еще попасть в правильную волновую форму. Поэтому это уже не только геометрическая оптика, а волновая оптика.

## Ограничения модели

Здесь нет:

- точных мод ступенчатого волокна через функции Бесселя;
- поляризации;
- отражения от торца волокна;
- углового рассогласования;
- дефокусировки вдоль оси;
- изгибов волокна.

Это базовая модель для понимания принципа ввода света в одномодовое оптоволокно.
