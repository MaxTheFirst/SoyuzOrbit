# Проект 04. Хроматическая аберрация

## Коротко

Хроматическая аберрация - это ошибка линзы, при которой разные цвета фокусируются в разных местах.

Белый свет состоит из разных длин волн. Синяя, зеленая и красная части света проходят через стекло немного по-разному. Поэтому простая линза не может собрать все цвета строго в одну точку.

## Что мы здесь исследуем

Скрипт показывает, как меняется фокусное расстояние одной и той же BK7-линзы для разных длин волн:

- синий свет;
- голубой свет;
- зеленый свет;
- желтый свет;
- красный свет.

Главная идея:

```text
цвет изменился -> показатель преломления изменился -> фокус изменился
```

## Что такое показатель преломления

Показатель преломления `n` показывает, насколько сильно материал меняет скорость и направление света.

Для воздуха примерно:

```text
n = 1
```

Для стекла:

```text
n > 1
```

У стекла `n` немного разный для разных цветов. Это называется дисперсией.

## Что такое BK7

BK7 - распространенное оптическое стекло. Оно часто используется в линзах, призмах и учебных оптических моделях.

В проекте показатель преломления BK7 считается по формуле Sellmeier. Эта формула уже есть в общем модуле проекта:

```text
lens_wave_optics.py
```

## Что используется в коде

Файл:

```text
chromatic_aberration.py
```

Он использует:

- `numpy`;
- `matplotlib`;
- `LensSpec` из общего модуля;
- `bk7_refractive_index`;
- `effective_focal_length`;
- `back_focal_length`.

## Что такое EFL и BFL

В скрипте печатаются две величины.

`EFL` - effective focal length, эффективное фокусное расстояние. Это удобная теоретическая характеристика линзы.

`BFL` - back focal length, заднее фокусное расстояние. Это расстояние от задней стороны линзы до фокуса.

Для простой учебной картины можно думать так:

```text
BFL показывает, где реально поставить экран за линзой
```

## Как работает скрипт

1. Берется одна и та же линза:

- радиус передней поверхности;
- радиус задней поверхности;
- толщина;
- апертура.

2. Для каждой длины волны считается показатель преломления BK7.

3. Для каждой длины волны считается фокусное расстояние.

4. Результаты печатаются таблицей.

5. Строится график:

- слева фокусное расстояние как функция длины волны;
- справа вертикальные линии, показывающие, где фокусируются разные цвета.

## Как запускать

Из корня репозитория:

```bash
./.venv/bin/python projects/04_chromatic_aberration/chromatic_aberration.py
```

Через `uv`:

```bash
uv run python projects/04_chromatic_aberration/chromatic_aberration.py
```

## Что должно появиться

В консоли:

- таблица `длина волны -> n -> EFL -> BFL`;
- смещение каждого цвета относительно зеленого фокуса.

На графиках:

- зависимость фокуса от цвета;
- отдельные положения фокусов для разных цветов.

## Как читать результат

Если фокусы разных цветов не совпадают, на экране невозможно получить идеально резкую белую точку простой линзой.

Если поставить экран в зеленый фокус, красный и синий будут немного не в фокусе. Это дает цветные ореолы.

## Почему это важно

Это объясняет:

- цветные края вокруг ярких объектов;
- почему телескопы и объективы используют несколько линз;
- зачем нужны ахроматы и апохроматы;
- почему стекло выбирают не только по форме, но и по дисперсии.

## Ограничения модели

Здесь нет:

- полного волнового распространения для каждого цвета;
- поглощения света в стекле;
- покрытий на линзах;
- сложных многолинзовых объективов.

Проект показывает саму причину хроматической аберрации.
