# Проект 02. Простая модель глаза

## Коротко

Этот проект показывает глаз как оптическую систему:

```text
свет -> зрачок -> линза глаза -> сетчатка
```

Сетчатка здесь работает как экран. Если линза собирает свет точно на сетчатке, изображение резкое. Если фокус оказался перед сетчаткой или за сетчаткой, точка превращается в размытое пятно.

## Что мы здесь исследуем

Скрипт показывает три случая:

1. Нормальный глаз: фокус попадает на сетчатку.
2. Фокус перед сетчаткой: похоже на близорукость.
3. Фокус за сетчаткой: похоже на дальнозоркость.

Отдельно скрипт показывает, как размер зрачка влияет на размер дифракционного пятна.

## Что такое зрачок

Зрачок - это отверстие, через которое свет входит в глаз.

В темноте зрачок становится больше. Света проходит больше, но оптические ошибки обычно видны сильнее.

На ярком свету зрачок становится меньше. Света меньше, но часть ошибок уменьшается. При слишком маленьком зрачке начинает заметнее работать дифракция.

## Что такое сетчатка

Сетчатка - это слой в задней части глаза, где свет превращается в нервный сигнал. В модели это просто экран на фиксированном расстоянии от линзы глаза.

В скрипте расстояние до сетчатки задано как:

```text
17 мм
```

Это не медицинская точная модель глаза конкретного человека. Это учебная оптическая схема.

## Что значит "фокус попал"

Линза должна собрать параллельный свет от далекого объекта в точку на сетчатке.

Если фокусное расстояние линзы равно расстоянию до сетчатки:

```text
f = retina_distance
```

точка получается самой резкой.

Если:

```text
f < retina_distance
```

лучи сходятся до сетчатки, а на сетчатке уже снова расходятся.

Если:

```text
f > retina_distance
```

лучи еще не успели сойтись на сетчатке.

В обоих случаях получается размытое пятно.

## Что используется в коде

Файл:

```text
eye_model.py
```

Библиотеки:

- `numpy`;
- `matplotlib`;
- FFT.

Модель использует дифракцию Френеля в фокальной плоскости. Для человека без физики можно думать так:

```text
мы берем волну в зрачке и математически переносим ее на сетчатку
```

## Как работает скрипт

1. Создается круглый зрачок.

2. Вводится фаза линзы глаза.

Фаза - это задержка волны. Линза задерживает разные части волны по-разному, из-за этого волна начинает сходиться.

3. Считается остаточная ошибка фокуса.

Если линза настроена идеально, ошибка равна нулю.

4. Через FFT строится распределение яркости на сетчатке.

5. Для каждого случая считается RMS-радиус пятна.

RMS-радиус - это численная мера размытия. Чем он меньше, тем резче точка.

## Как запускать

Из корня репозитория:

```bash
./.venv/bin/python projects/02_eye_model/eye_model.py
```

Через `uv`:

```bash
uv run python projects/02_eye_model/eye_model.py
```

## Что должно появиться

В консоли:

- длина волны;
- расстояние до сетчатки;
- диаметр зрачка;
- ошибка фокуса для каждого случая;
- RMS-радиус пятна.

На графиках:

- карты пятна на сетчатке;
- срезы яркости через центр;
- сравнение разных размеров зрачка.

## Как читать графики

Маленькое яркое пятно означает резкое изображение.

Большое размазанное пятно означает, что фокус промахнулся.

Кольца вокруг центрального пятна - это дифракция. Они появляются даже в идеальной системе.

## Почему это важно

Проект объясняет:

- почему близорукость и дальнозоркость связаны с положением фокуса;
- почему маленький зрачок может улучшать резкость;
- почему идеальная точка все равно не становится бесконечно малой;
- почему оптика глаза похожа на маленькую камеру.

## Ограничения модели

Здесь нет:

- роговицы как отдельной поверхности;
- хрусталика с переменной формой;
- астигматизма;
- клеток сетчатки;
- нейронной обработки изображения;
- цветового зрения.

Это простая физическая модель для понимания фокуса и дифракции.
