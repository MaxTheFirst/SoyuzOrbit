# Проект 06. Фурье-оптика изображения

## Коротко

Этот проект показывает, почему линза с ограниченной апертурой теряет мелкие детали изображения.

Любую картинку можно представить как смесь простых узоров:

- медленные изменения яркости;
- средние детали;
- очень частые мелкие штрихи.

В языке оптики это называется пространственными частотами.

## Что мы здесь исследуем

Скрипт берет искусственную тестовую картинку с линиями разной толщины и показывает, что происходит, если через линзу проходят не все пространственные частоты.

Главная идея:

```text
маленькая апертура -> меньше высоких частот -> картинка более размытая
```

## Что такое пространственная частота

Пространственная частота показывает, как быстро меняется картинка в пространстве.

Примеры:

- большое белое пятно на черном фоне - низкая частота;
- толстые полосы - средняя частота;
- очень тонкие частые полосы - высокая частота.

Мелкие детали требуют высоких пространственных частот.

## Почему здесь появляется Фурье

Преобразование Фурье раскладывает картинку на частоты.

Для звука это похоже на разложение сложного звука на низкие и высокие ноты.

Для изображения это разложение на крупные и мелкие детали.

Линза в фокальной плоскости фактически строит Фурье-спектр поля. Поэтому Фурье-оптика напрямую связана с реальной оптикой.

## Что используется в коде

Файл:

```text
fourier_imaging.py
```

Библиотеки:

- `numpy`;
- `matplotlib`;
- FFT.

Код не использует внешние картинки. Тестовый объект создается прямо в массиве.

## Как работает скрипт

1. Создается тестовая картинка.

На ней есть:

- рамка;
- группы вертикальных полос;
- группы горизонтальных полос;
- диагональные линии.

2. Считается Фурье-спектр картинки.

Центр спектра соответствует крупным деталям.

Дальние области спектра соответствуют мелким деталям.

3. Создается круглая маска в частотной области.

Эта маска играет роль апертуры линзы:

```text
внутри круга частоты проходят
снаружи круга частоты отбрасываются
```

4. Картинка восстанавливается обратно.

Если маска маленькая, восстанавливаются только грубые детали.

Если маска большая, проходят и мелкие детали.

## Как запускать

Из корня репозитория:

```bash
./.venv/bin/python projects/06_fourier_imaging/fourier_imaging.py
```

Через `uv`:

```bash
uv run python projects/06_fourier_imaging/fourier_imaging.py
```

## Что должно появиться

В консоли:

- короткое объяснение, какие апертуры используются.

На графиках:

- исходный объект;
- Фурье-спектр;
- круглая апертура в спектре;
- изображения после разных размеров апертуры;
- срез яркости через картинку.

## Как читать результат

Если апертура маленькая, тонкие линии пропадают или сливаются.

Если апертура больше, тонкие линии видны лучше.

На срезе яркости это выглядит как сглаживание резких переходов.

## Почему это важно

Это объясняет:

- почему объективы имеют ограниченную резкость;
- почему мелкие детали теряются первыми;
- что такое частотная фильтрация;
- почему MTF в оптике связан с контрастом мелких деталей.

## Связь с телескопом и глазом

Телескоп, глаз и камера не просто "увеличивают". Они передают пространственные частоты.

Если система не пропускает высокие частоты, мелкие детали исчезают, даже если изображение потом увеличить.

## Ограничения модели

Здесь используется простая когерентная модель.

В реальной фотографии важны еще:

- некогерентный свет;
- шум;
- пиксели сенсора;
- цвет;
- аберрации;
- движение.

Но базовая идея фильтрации деталей через апертуру показана правильно.
