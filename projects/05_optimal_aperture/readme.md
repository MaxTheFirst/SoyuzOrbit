# Проект 05. Оптимальная апертура

## Коротко

Интуитивно кажется, что чем больше отверстие линзы, тем всегда лучше. На самом деле есть компромисс.

Маленькая апертура:

- пропускает меньше света;
- дает большое дифракционное пятно.

Большая апертура:

- пропускает больше света;
- уменьшает дифракционное пятно;
- сильнее проявляет ошибки формы линзы.

Этот проект ищет разумный диаметр апертуры для простой сферической линзы.

## Что мы здесь исследуем

Мы меняем диаметр открытой части линзы и считаем:

- дифракционный предел;
- реальный размер пятна;
- фазовую ошибку;
- Strehl ratio.

Главный вопрос:

> Где находится компромисс между дифракцией и аберрациями?

## Что такое сферическая аберрация

Сферическая линза имеет поверхности, похожие на части сферы.

Проблема в том, что края такой линзы и центр не всегда собирают свет в одну и ту же точку. Из-за этого фокус растягивается, а пятно становится хуже.

Это называется сферической аберрацией.

## Что такое дифракционный предел

Даже идеальная линза с круглой апертурой не дает бесконечно маленькую точку.

Приближенный радиус первого темного кольца:

```text
Airy = 1.22 * lambda * f / D
```

Где:

- `lambda` - длина волны;
- `f` - фокусное расстояние;
- `D` - диаметр апертуры.

Если `D` растет, дифракционное пятно уменьшается.

## Почему не стоит просто открыть апертуру полностью

Для идеальной линзы большая апертура почти всегда лучше.

Для реальной сферической линзы края могут портить волну. Тогда при увеличении апертуры сначала становится лучше, а потом может стать хуже.

Этот проект как раз показывает такую конкуренцию.

## Что используется в коде

Файл:

```text
optimal_aperture.py
```

Он использует общий модуль:

```text
lens_wave_optics.py
```

Из него берутся:

- `LensSpec`;
- `real_lens_transmission`;
- `lens_thickness`;
- `effective_focal_length`;
- `airy_radius`;
- `bk7_refractive_index`.

## Как работает скрипт

1. Задается одна сферическая BK7-линза.

2. Берется набор диаметров апертуры.

3. Для каждого диаметра строится поле после реальной линзы.

Поле здесь комплексное. У него есть:

- амплитуда;
- фаза.

4. Считается фокальная картина через FFT.

5. Считается RMS-радиус пятна.

RMS-радиус - это средний радиус энергии пятна. Чем меньше, тем лучше.

6. Считается радиус Эйри для идеального дифракционного предела.

7. Считается Strehl ratio.

## Что такое Strehl ratio

Strehl ratio - это мера качества оптики.

Простое объяснение:

```text
Strehl = яркость центрального пика реальной линзы / яркость центрального пика идеальной линзы
```

Если значение близко к `1`, линза почти идеальная.

Если значение сильно меньше `1`, свет размазан по пятну и кольцам.

## Как запускать

Из корня репозитория:

```bash
./.venv/bin/python projects/05_optimal_aperture/optimal_aperture.py
```

Через `uv`:

```bash
uv run python projects/05_optimal_aperture/optimal_aperture.py
```

## Что должно появиться

В консоли будет таблица:

```text
D, мм | Airy, мкм | RMS пятна, мкм | Strehl | RMS фазовой ошибки, рад
```

На графиках:

- размер пятна против диаметра апертуры;
- дифракционный предел;
- Strehl ratio;
- фазовая ошибка;
- примеры пятен для малой, средней и большой апертуры.

## Как читать результат

Если апертура мала, дифракционный предел большой.

Если апертура слишком велика, фазовая ошибка и аберрации могут портить пятно.

Минимум графика RMS-пятна показывает лучший компромисс для выбранной линзы.

## Почему это важно

Это объясняет:

- почему в камерах есть диафрагма;
- почему объективы часто резче не на полностью открытой диафрагме;
- почему дифракция ограничивает слишком закрытую диафрагму;
- почему размер апертуры это не только "больше света".

## Ограничения модели

Здесь используется:

- одна простая сферическая линза;
- один цвет света;
- скалярная волновая модель;
- идеальная поверхность без царапин и шероховатости.

В реальном объективе много линз, покрытий и механических ограничений.
