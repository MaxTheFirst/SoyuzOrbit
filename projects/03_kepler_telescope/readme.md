# Проект 03. Телескоп Кеплера

## Коротко

Телескоп Кеплера состоит из двух собирающих линз:

```text
объектив -> промежуточное изображение -> окуляр
```

Объектив собирает свет от далекого объекта и строит маленькое изображение внутри телескопа. Окуляр работает как увеличительное стекло для этого промежуточного изображения.

## Что мы здесь исследуем

Скрипт показывает:

- как идут лучи через две линзы;
- почему расстояние между линзами примерно равно `f_objective + f_eyepiece`;
- как получается угловое увеличение;
- почему увеличение зависит от отношения фокусных расстояний.

Главная формула:

```text
M = -f_objective / f_eyepiece
```

Где:

- `M` - угловое увеличение;
- `f_objective` - фокусное расстояние объектива;
- `f_eyepiece` - фокусное расстояние окуляра.

Минус означает переворот направления. В телескопе Кеплера изображение перевернуто.

## Что такое объектив

Объектив - первая линза телескопа. Она смотрит на объект.

Для телескопа объектив особенно важен, потому что он:

- собирает свет;
- задает дифракционный предел;
- строит промежуточное изображение.

Большой объектив дает больше света и лучшее разрешение.

## Что такое окуляр

Окуляр - линза, в которую смотрит глаз.

Он не создает новые детали. Он увеличивает угловой размер того изображения, которое уже построил объектив.

Если объектив не смог разделить две близкие звезды, окуляр не вернет потерянную информацию.

## Что используется в коде

Файл:

```text
kepler_telescope.py
```

Библиотеки:

- `numpy`;
- `matplotlib`.

В этом проекте используется лучевая модель. Это проще, чем полная волновая оптика. Мы рисуем несколько лучей и смотрим, как линзы меняют их направление.

## Как работает лучевая модель

Луч описывается двумя числами:

```text
height - высота луча над оптической осью
angle  - угол луча
```

Свободное пространство меняет высоту луча:

```text
height_new = height + distance * angle
```

Тонкая линза меняет угол:

```text
angle_new = angle - height / focal_length
```

Этого достаточно, чтобы понять базовую работу телескопа.

## Как работает скрипт

1. Задаются фокусные расстояния двух линз.

2. Расстояние между линзами берется равным:

```text
f_objective + f_eyepiece
```

Это делает телескоп афокальным. Значит параллельный пучок на входе снова становится параллельным пучком на выходе, но с другим углом.

3. Для нескольких входных углов строятся лучи.

4. Скрипт печатает, где находится промежуточное изображение:

```text
y = f_objective * input_angle
```

5. Скрипт печатает выходной угол после окуляра.

## Что должно появиться

В консоли:

- фокус объектива;
- фокус окуляра;
- расстояние между линзами;
- угловое увеличение;
- дифракционный предел объектива;
- преобразование входного угла в выходной.

На графиках:

- ход лучей через телескоп;
- зависимость выходного угла от входного.

## Как читать график лучей

Вертикальная линия слева - объектив.

Вертикальная линия справа - окуляр.

Лучи разных цветов соответствуют разным направлениям на небе.

Если после окуляра лучи снова идут почти параллельно, телескоп настроен на глаз, который смотрит вдаль.

## Связь с волновой оптикой

Этот проект специально проще, чем остальные. Он объясняет геометрию двух линз.

Но телескоп все равно ограничен волнами. Его объектив имеет дифракционный предел:

```text
theta = 1.22 * lambda / D
```

Поэтому проект 01 хорошо дополняет этот проект.

## Ограничения модели

Здесь не учитываются:

- толщина линз;
- дифракционные пятна в каждой плоскости;
- аберрации;
- реальные окулярные схемы;
- поле зрения;
- виньетирование;
- атмосфера.

Это базовая схема, чтобы понять принцип двух собирающих линз.
